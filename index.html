WarpGen

Генератор конфигов Cloudflare WARP для AmneziaWG 2.x и WireGuard

Настройки конфига
Если на macOS Amnezia-формат нестабилен — попробуйте WireGuard (vanilla).
Или нажмите «Найти лучший endpoint» ниже — warpscout просканирует сеть.
I1 — валидный первый пакет (QUIC/DNS/…), под который маскируется хендшейк. «Свой домен» генерирует настоящий QUIC Initial.
Split-tunnel работает по IP/подсетям: домены резолвятся при генерации (DoH).
Для игр это best-effort: IP бэкендов меняются, иногда нужно обновить конфиг.
🛰 warpscout — поиск рабочего endpoint
Бинарник warpscout не найден. Запустите npm run fetch:warpscout (или он подтянется при сборке).
🛡 DPI-обход WARP (winws / zapret2)
⚠ Требует прав администратора (UAC) и загружает драйвер WinDivert. winws2/WinDivert/Lua скачиваются с github.com/bol-van/zapret-win-bundle при первом запуске. Только Windows.
